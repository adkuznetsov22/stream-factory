# live-clipper

Автоматические нарезки из live-стримов Twitch без участия человека: стрим смотрится онлайн, момент
находится по всплеску чата и звука, клип режется в вертикаль 9:16 с субтитрами и сразу публикуется.

```
discovery (Twitch GQL, раз в 60 с) ─▶ Recorder: streamlink | ffmpeg → 2-секундные сегменты, буфер 15 мин
                                   └▶ ChatMonitor: анонимный IRC, взвешенная активность по секундам
сегмент ─▶ громкость (dBFS/с) ─▶ Detector: robust z-score чата + звука ─▶ Moment
Moment ─▶ ClipJob: склейка буфера → Whisper (субтитры) → заголовок (LLM/шаблон) → ffmpeg 1080x1920 ─▶ publish
```

Ключи Twitch не нужны (используется публичный web client id, как в streamlink).

## Запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # нужен ffmpeg в системе
cp .env.example .env
export PATH=$PWD/.venv/bin:$PATH

python -m live_clipper discover                        # кого будем писать прямо сейчас
python -m live_clipper test buster --record 60 --clip 30   # проверочный клип с одного канала
python -m live_clipper run                             # боевой режим
```

Docker: `docker compose up -d --build`.

## Админка

`python -m live_clipper run` поднимает админку на `http://<host>:8080` (порт `LC_ADMIN_PORT`).
Пароль — `LC_ADMIN_PASSWORD`; если не задан, генерируется в `data/admin_password.txt`.

Интерфейс — React + TypeScript + Tailwind в `web/` (сборка `cd web && npm ci && npm run build` кладёт его в
`live_clipper/static/dist`; Docker собирает сам). Данные обновляются в реальном времени через SSE (`/api/events`).

Разделы:
1. **Обзор**: чек-лист первого запуска, сводка за сутки, хайп по стримам, состояние площадок, ошибки.
2. **Эфир**: живые кадры стримов, шкала хайпа с порогом и отметками моментов, вклад чата и звука, чат,
   «Клип сейчас» на 15–90 с.
3. **Клипы**: очередь «ждут решения», фильтры, горячие клавиши (J/K, P, R).
   - *Публикация*: заголовок, описание, перегенерация, превью подписи для каждой площадки, выбор площадок.
   - *Монтаж*: сдвиг начала и конца по исходнику с запасом (`source_padding`), текст плашки, раскладка,
     правка субтитров, пересборка.
   - *Почему нарезан*: вклад чата и звука, порог, эмоуты, чат и речь в момент пика.
   - Дубли совместных стримов помечаются и не публикуются автоматически.
4. **Публикации**: журнал постов по площадкам: ссылка, ошибка, повтор, удаление поста с площадки,
   просмотры (VK, YouTube).
5. **Площадки**: ключи, проверка прав, тестовый пост, режим «авто» / «на одобрении», мин. балл, лимит в сутки,
   пауза, тихие часы, шаблон подписи, время следующего поста. Без успешной проверки площадка не включится.
6. **Стримеры**: белый и чёрный список, найденные авто-поиском; профиль: раскладка, вебка (выделяется мышкой
   на живом кадре), чувствительность, свои хэштеги.
7. **Настройки**: детектор, длина клипа, субтитры, хэштеги, OpenRouter, хранение. Применяются без перезапуска.
8. **Здоровье**: задержки «момент → клип → пост», состояние записи и чата, диск и прогноз, ошибки, журнал,
   привязка алертов в личку Telegram.

Файлы удаляются автоматически: исходники для монтажа через `retention_source_hours` (6 ч), неопубликованные
клипы через `retention_hours` (12 ч), опубликованные через `retention_published_hours` (72 ч).

Клипы: `data/clips/<login>_<ts>/src.ts` (исходник), `source.mp4` (превью исходника), `clip.mp4`, `thumb.jpg`, `meta.json`; история и публикации — `data/clips.db`.

## Публикация

Площадки и ключи заводятся в админке. При первом запуске ключи из `LC_TELEGRAM_*`, `LC_VK_*`, `LC_YOUTUBE_*`
переносятся в площадку (включается, только если она есть в `LC_PUBLISH_TARGETS`).

| Площадка | Что нужно |
|---|---|
| Telegram | токен бота от @BotFather, бот — админ канала с правом публикации |
| VK | токен с правами `video,wall,groups,offline` и id группы (`video.save`) |
| YouTube | OAuth client + refresh token со scope `youtube.upload`; дефолтная квота ≈ 6 загрузок/день на проект |

Ключи хранятся в `data/clips.db` в открытом виде: каталог `data` не должен быть доступен посторонним,
админку наружу — только через HTTPS-прокси.

## Настройка

Стартовые параметры — переменные `LC_*` (см. `live_clipper/config.py` и `.env.example`).
